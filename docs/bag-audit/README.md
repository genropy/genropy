# JavaScript Bag compatibility audit

Scope: every legacy prototype member of GnrBag, GnrBagNode, GnrBagResolver,
GnrBagFormula, GnrBagGetter, GnrBagCbResolver, GnrDomSource and GnrDomSourceNode,
including inherited members, constructor fields and exported namespace names.
The standalone implementation is checked through the selected adapter's actual
prototype chain, not by searching only the adapter source.

## Reproducible evidence

- `surface.md` / `surface.json`: 480 class/member entries, including inherited
  occurrences; generated by `node gnrjs/tests/bag_audit_inventory.cjs`.
- `callsites.json`: candidate calls in 2,115 JS/Python source files, including
  embedded JS; generated by `python3 gnrjs/tests/bag_audit_callsites.py`.
  Matches do not establish receiver type. Computed method names and unknown
  applications cannot be proven by this scan.
- `gnrjs/tests/bag_surface_audit.test.js`: exhaustive member availability,
  constructor fields and namespace checks, plus differential behavior cases.
- `gnrjs/tests/bag_semantics_audit.test.js`: present-method semantic comparison.
- `gnrjs/tests/bagnode_legacy_audit.test.js`: node state and behavior comparison.
- `gnrjs/tests/resolver_compatibility.test.js`: all four resolver classes.
- Existing native-class and real form/source consumer regressions remain part
  of the combined test run. The harness loads the real Dojo Deferred source.

## Missing Bag entry points

The missing entry points below were compared against their legacy bodies and
restored as explicit compatibility methods. No legacy runtime import or mixin
is used. Core storage still comes from the standalone classes. This necessarily
increases the adapter: API compatibility includes behavior, not only aliases.

| Members | Evidence / treatment |
| --- | --- |
| asHtmlTable, asObjList | Differential row content, labels and HTML output |
| asNestedTable | Differential formatting and omitted empty values |
| __str__, __str2__, asString | Differential scalar formatting; legacy visited-state behavior retained |
| moveNode | Differential order, insertion and deletion notifications |
| merge, pathsplit | Preserved legacy empty compatibility hooks |
| _getNode, rowchild | Differential creation, attributes and default values |
| set, _insertNode | Reviewed together with setItem/addItem in semantic audit |
| backrefOk | Differential attached parent/node graph check |
| runTrigger, onNodeTrigger | Bridged to selected subscriber maps; direct creation and bubbling test |
| toXmlBlock | Differential typed values, attributes and nested content |
| formula, defineSymbol, defineFormula | Differential explicitly bound evaluation; inherited legacy factory defects recorded in resolver report |
| get_modified, set_modified, _setModified | Differential enable/reset/disable subscription lifecycle |
| getIndex, _deepIndex, getIndexList | Differential nested enumeration; explicit scalar/null guard fixes legacy `in`-on-scalar error |
| doWithItem | Differential value/default callbacks; Deferred implementation retained |

## Verification limits and release gate

Zero missing methods is a structural check, not a passing behavioral audit.
Each semantic report distinguishes tested compatibility, intentional differences,
legacy defects and unresolved discrepancies. Tests deliberately retain failures
for unresolved node behavior. No claim is made that all parameter combinations,
third-party applications, browsers or network transports have been exercised.

The audit changes have not been committed, published or loaded by a server
restart. Core node changes rejected by automatic approval review are separate
proposed changes; the behavioral test suite must pass before deployment.

## Current result

Selected-mode combined run: **136 tests, 128 passed, 8 failed, no skips**.
Full failing assertions are in `verification.txt`. Remaining failures concern
node constructor state, orphan parent nullability, value/attribute event fields,
callback/return/fired semantics, replaced Bag backrefs and DOM source detachment.
These are unresolved compatibility defects, not ignored or expected passes.
